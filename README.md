# Personal dotfiles
- Feel free to use them any way you want
```bash
git clone --recurse-submodules https://github.com/FajiCapiDuCk/dotfiles
```

- [Konsole(KDE terminal)](https://invent.kde.org/utilities/konsole)
- [Foot(Terminal)](https://codeberg.org/dnkl/foot)
- [Picom(Compositor)](https://github.com/yshui/picom)
- [Polybar](https://polybar.github.io/)
- [rofi](https://github.com/davatorium/rofi)
- [alacritty](https://alacritty.org/)
- [i3wm](https://i3wm.org/)
- [sway](https://swaywm.org/)
- [dux shell](https://duxlabs.dev/)
